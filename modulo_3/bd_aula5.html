Introdução

Agora na Base de Dados Tabela_Amigos vai acrescentar mais dois campos: Data de Nascimento e Idade e usar SOMA, MÉDIA, MÁXIMO, MÍNIMO para fazer análises estatísticas rápidas e relembrar funções do Excel.

💡 No Excel as funções poupam horas de cálculo manual.

Fórmulas a usar

=SOMA(F2:F6)Soma valores do intervalo
=MÉDIA(F2:F6)Média aritmética
=MÁXIMO(F2:F6)Maior valor
=MÍNIMO(F2:F6)Menor valor

Como o Excel calcula?

Fórmula Idade: =INT((HOJE() - DataNasc)/365,25)
Exemplo: Chloé 12/03/2005 → =INT((HOJE()-"12/03/2005")/365,25)
