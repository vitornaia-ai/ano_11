Aventura Imaginária

Para aprendermos a trabalhar com Bases de Dados, vamos organizar dados a partir de uma aventura sobre Desportos Radicais.

Dez amigos milionários, cada um de um país diferente, reuniram-se em Portugal para uma aventura única: aprender Excel enquanto praticam desportos radicais ao redor do mundo. Cada um deles é especialista em um desporto radical diferente e irá apresentar a sua emocionante atividade ao grupo.

Vamos começar por analisar e organizar os amigos. Cada amigo é um registo, cada caraterística é um campo.

💡 Esta é a base de tudo! Sem dados bem organizados, não há análise.

Criar a Base de Dados no Excel

No Excel vamos criar uma lista com os 10 amigos milionários. Cada linha será o registo de um amigo, e cada coluna identifica o tipo de dado.

NomeCaracterísticasFotoPaísCidadeFortunaProveniência
Campo = coluna (tipo de dado) • Registo = linha (um amigo)

Atividade Prática

  1. Vai a office.com > Excel > Livro em branco
  2. Duplo clique no nome da folha em baixo
  3. Colunas: Nome, Características, Fotografia, Continente, País, Fortuna, Proveniência
  4. Inserir > Imagens > Dentro da célula para ficar organizada
  5. Ficheiro > Guardar Como > OneDrive
  6. Formatar como Tabela, filtros, larguras ajustadas
