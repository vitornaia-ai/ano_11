Aula 3: Funções Básicas – SOMA, MÉDIA, MÁXIMO, MÍNIMO

Objetivo

Calcular estatísticas básicas sobre a "Tabela_Amigos".

Explicação

Na "Tabela_Amigos" vamos acrescentar o campo data de nascimento e depois vamos aplicar funções básicas como SOMA, MÉDIA, MÁXIMO e MÍNIMO para ajudar na análise rápida da informação.

Fórmulas

=SOMA(F2:F6)   =MÉDIA(F2:F6)    =MAXIMO(F2:F6)   =MINIMO(F2:F6)

Atividade

  1. Abra o livro "Tour_Radical".
  2. Na tabela "Tabela_Amigos" acrescente os campos "Data de Nascimento" e "Idade" no final da tabela.
  3. Escreva as seguintes datas de nascimento para cada amigo.

    4. Nome Data de Nascimento
    Chloe 12/03/2005
    Tane 28/07/2003
    Jacques 05/11/1998
    Ana 16/06/2004
    Khalid 22/01/2001
    Yuki 30/04/1997
    Amir 18/12/2000
    Naledi 03/08/1994
    Klaus 25/05/1982
    João 14/06/2003

  4. No campo idade escreva a fórmula que calcula a idade de cada um. (Entre no LMArena e escreva o prompt para saber a fórmula).
  5. Calcular estatísticas básicas:
    1. Indique qual é a soma da idade de todos os amigos.
    2. Indique qual é média da idade dos amigos.
    3. Indique qual é a idade maior.
    4. Indique qual é a idade menor.
    5. Indique qual é a soma das fortunas de todos os amigos.
    6. Indique qual é média das fortunas dos amigos.
    7. Indique qual é a maior fortuna.
    8. Indique qual é a menor fortuna.
  6. Guarde o livro no Onedrive.
  7. Crie uma apresentação sobre o que fez nessa aula para ser apresentada na aula da próxima semana.
