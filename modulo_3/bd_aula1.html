Bases de Dados

Imagine uma enorme coleção de objetos espalhados por todo o lado.Agora imagine todos esses objetos guardados e arrumados em móveis e caixas.

As Bases de Dados são a segunda imagem mas em termos digitais.

Bases de Dados são conjuntos de dados estruturados em CAMPOS (colunas) e REGISTOS (linhas). Um campo contém um item de dado, ex: "Vitor" no campo Nome.

Nome (Campo)IdadeCidade
Campo = coluna • Registo = linha

Gestão de Bases de Dados

Quando já temos uma estrutura de dados criada o passo seguinte é fazer a gestão desses dados. A gestão é organizar, guardar, procurar e manter os dados.
