Aula 4: Base de Dados dos Desportos Radicais

Objetivo

Criar uma lista estruturada com os dados dos desportos radicais.

Explicação

Vamos criar uma lista com os desportos radicais dos 10 amigos milionários. Esta lista contém várias linhas que vão registar o desporto e o equipamento que é necessário comprar para o praticar e cada coluna identifica o tipo de dado que vai guardar (nome do desporto, equipamento, preço mais caro).

  1. Vai assumir o papel do amigo milionário que vai tentar convencer os outros a irem praticar o seu desporto.

  3. Os pontos a pesquisar são:
    1. O que é o [Desporto Radical].
    2. Imagens do [Desporto Radical].
    3. Equipamento que é necessário para praticar o [Desporto Radical] e preço do equipamento mais caro.
    4. Um vídeo sobre o [Desporto Radical].
  4. Crie uma apresentação sobre o [Desporto Radical] seguindo os passos da seção seguinte.

    5. Passos

    2. Escreva o seguinte prompt para ajudar no desenvolvimento da apresentação:

O 1º será a capa, o 2º explica o que é o desporto, o 3º explica como se pratica, o 4º mostra imagens sobre o desporto, o 5º indica qual é o equipamento necessário para o praticar e o preço mais caro do equipamento, o 6º indicará um link para o vídeo mais visto desse desporto, o 7º mostra a tua opinião porque esse deve ser o desporto que todos os amigos devem experimentar praticar e o 8º indica as fontes de consulta que foram utilizadas para construir o trabalho.
